# Campus_Lilo
Gampus — Онлайн-платформа оголошень
це сучасний вебзастосунок (онлайн-маркетплейс / дошка оголошень), призначений для зручного розміщення, пошуку та купівлі/продажу товарів і послуг. Платформа дозволяє користувачам швидко публікувати власність для продажу, знаходити вигідні пропозиції поблизу за категоріями та регіонами, а також зберігати вподобані товари.

2. Проблема, мета та цільова аудиторія
   -Складність і неефективність швидкого збуту уживаних або незадіяних речей.
   - Відсутність зручного та сучасного локального сервісу для швидкого пошуку товарів за деталізованими категоріями та містами.
Мета:
Створити швидкий, безпечний та інтуїтивно зрозумілий вебмаркетплейс, який спрощує процес купівлі-продажу між людьми та надає простий доступ до оголошень у будь-якій точці країни.

Цільова аудиторія:
Приватні продавці:** люди, які бажають продати або віддати ненужні речі.
Покупці: користувачі, які шукають товари (електроніка, авто, меблі, одяг тощо) чи послуги за вигідними цінами.
Шукачі роботи та роботодавці:** користувачі розділу з пошуку вакансій та кандидатів.

  4. Основні функції та сторінки^
     - Авторизація та реєстрація:** вхід за e-mail або через соціальні мережі.
     - Пошукова система:** гнучкий пошук за текстовим запитом та містом/регіоном.
     - Каталог за категоріями:** швидка навігація (Електроніка, Авто, Нерухомість, Робота, Дім і сад, Мода, Хобі, Тварини).
     - Публікація оголошень:** завантаження фотографій, опис, вказання ціни, стану та локації.
     - Модуль «Обране»:** збереження оголошень для швидкого доступу.
